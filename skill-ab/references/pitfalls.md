# 常见坑

| 现象 | 真因 | 处置 |
|---|---|---|
| A 写出来越来越像散文、后几章明显乏力 | 批量太大 / brief 没带卷级远景 | 批量降到 3–5，brief 必带卷目标与里程碑 |
| B 每批都 PASS | 同源盲点：B 与 A 同一模型，偏好相同 | 换审查维度；或让 B 先做"违禁词与负清单逐条核对"再做文学判断 |
| B 提的意见改完更差 | B 越权改情节 | 只接受"最小改法"，改写动作还给 A；B 的输出禁止出现整段新文本 |
| 伏笔越写越乱 | 回写追踪被省 | 每章必须追加 状态/伏笔；`validate_novel.py` 逾期检查当硬门禁 |
| 状态文件冲突 | 并行写相邻章 | 同批串行；并行只用于不同卷/不同 POV 线 |
| 换会话后接不上 | 没 checkpoint / 播报缺失 | 续跑三件套：`项目.md` 进度、`CHANGELOG.md`、`成品/snapshots` 最新一份 |
| 字数忽高忽低 | 细纲 `字数` 字段没写 | 细纲必须带 `- 字数: N`，gate_all 用它对标 |
